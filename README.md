# Reading Log

A [Chickadee Bandit](https://chickadeebandit.com/app-library/reading-log) app.

Children log books they've read with ratings and notes. Adults see a summary across the whole family.

## Features

- Books with page counts, star ratings, and notes.
- A per-book progress bar.
- A family-wide summary for adults.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-reading-log/releases/latest/download/bundle.json
```
